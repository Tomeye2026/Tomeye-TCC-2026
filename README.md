## 📖 Breve descrição do projeto

Sistema Web PWA, voltado ao ramo agrícola da cultura do tomate, analisando a planta por meio de Inteligência Artificial e buscando possíveis doenças, como:

- Septoria
- Requeima
- Mofo das folhas
- Vírus do enrolamento amarelo
- Mancha bacteriana
